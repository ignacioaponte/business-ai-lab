What I'm building

- 4 Media Company
  Proyecto de companía de medios impulsada por IA, manejada por humanos. Combina el control de calidad humano con la producción con IA para producir contenido en nichos de alto consumo (Consumer intelligence, human curiosity y place intelligence). Conecta todo un pipeline con intervenciones manuales y controles de calidad estratégicos para producir contenido en masa sin perder calidad
- CE Argus
  Sistema automatizado de captación, selección y outreach a prospectos a los que se les pueda vender el sistema Content Engine. Funciona scrapeando places de Maps, pasándolos por un filtro de calidad antes de guardarlos (para evitar leads basura), se les hace la comunicación inicial + seguimiento y solo se le entrega la comunicación a un operador humano cuando ya el lead ha demostrado interés.
- Content Engine
  Proyecto principal. Es todo un sistema de creación de contenido en automático para negocios. Se ofrece en forma de paquetes, son cantidad de videos mensuales, estilo de video, y todo es hecho a la medida (se le hace una encuesta con preguntas clave al cliente antes de comenzar la producción. Incluye programación y edición automática de contenido hecho para vender y con copy optimizado para ser llamativo.
